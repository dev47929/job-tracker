# Frontend Interview Revision Topics

Based on the Job Tracker project, here's a comprehensive list of topics you should revise before your interviews:

## **React Fundamentals**

- `useState` hook (state management)
- `useEffect` hook (side effects, cleanup)
- `useContext` (context API for state sharing)
- Functional components vs Class components
- Props and prop drilling
- Conditional rendering (if/else, ternary operators)
- Lists and keys (`.map()`)
- Event handling (`onClick`, `onChange`, `onSubmit`)
- Forms and controlled components

## **Advanced React Patterns**

- Custom hooks
- Higher-Order Components (HOC)
- Render props
- Error boundaries
- React.memo for optimization
- useReducer (for complex state)
- useCallback and useMemo (performance optimization)

## **JavaScript (ES6+)**

- `async/await` functions
- Promises and `.then().catch()`
- Destructuring (objects and arrays)
- Spread operator (`...`)
- Template literals
- Arrow functions
- `setTimeout` and `setInterval`
- Try-catch error handling
- Array methods (`.map()`, `.filter()`, `.reduce()`)

## **API & Data Management**

- Fetch API
- HTTP methods (GET, POST, PUT, DELETE)
- JSON parsing
- Request headers
- Error handling from API responses
- localStorage (JWT token storage)
- Environment variables

## **Routing**

- React Router basics (`BrowserRouter`, `Route`, `Link`, `useNavigate`)
- Route parameters
- Nested routes
- Protected/private routes
- Redirect logic

## **Authentication & Security**

- JWT tokens (storage and usage)
- Login/Signup flows
- Token validation
- CORS issues
- XSS prevention basics

## **CSS & Styling**

- Tailwind CSS (utility classes)
- Responsive design
- Flexbox/Grid basics
- CSS classes in React (`className`)

## **Project Architecture**

- Component file structure
- Separation of concerns
- Reusable components
- DTO/Data Transfer Objects
- API integration patterns

## **Debugging & Tools**

- Browser DevTools (console, network tab)
- React DevTools extension
- Network request inspection
- Error handling and logging

## **Pro Tips for Interview Preparation**

- Build small projects using these concepts
- Create variations like a todo app, weather app, or notes app to solidify these skills
- Practice explaining your code and design decisions
- Be prepared to discuss trade-offs and performance considerations
- Have examples ready from your Job Tracker project
